§1 · Three dials

三个拨盘 三拨盘

每个生成都从这三个数字开始。拖它们 — 下面的标签会跟着变化，告诉你每个值适合什么。

SOUL · 灵魂

多少 personality？保守还是奔放？决定你会不会用 serif、会不会用大留白、会不会用暗调。

多少视觉冲击？仪表盘锁在 1–3，品牌页可以拉到 10。高于 7 一定要有真引擎 + reduced-motion fallback。

5/ 10

每屏多少信息？仪表盘拉满（8–9），品牌页压低（1–3）。密度高的页面必须有好的留白节奏。

§2 — BRAND REGISTER

Brand 注册：设计即产品

落地页 · 品牌站 · 上线页 · portfolio · hero page。 优化方向：视觉冲击 × 灵魂表达 × 第一印象。配 dark-by-default、grain、`clamp()` 大字、真实引擎。

通用工艺底线 brand 与 product 共用 — 这是最低线

Floor · 底线 #1
Tinted neutrals

不准用纯 #fff / #000。向 brand hue 偏 OKLCH 0.005–0.015。这一个动作就能让 80% 的廉价感消失。

Floor · 底线 #2
Hairline borders

rgba(255,255,255,.07–.22) 半透明边。硬 #ccc / #333 廉价读数 = 廉价感。

Floor · 底线 #3
Tinted shadows

阴影向 ink 染色（rgba(30,20,70,.06)），绝不纯黑。带 hue 的阴影才有质感。

Floor · 底线 #4
Contrast floors

正文 ink vs bg ≥ 7:1 · muted ≥ 3.5:1 · 组件 ≥ 3:1。亮暗模式分别测试，不能反色互换就以为 OK。

§3 — BRAND SUBSTRATE · HERO ENGINES

五套引擎 · 一站到底的视觉奇观

每个品牌页只该用 一套。下面是真实可跑的 mini 实现 — 鼠标移上去、滚动，等待，会动。

ENGINE A · THREE.JS + GLSL

粒子星系 / 3D 深度

天文学 · AI · 加密 · 网络图 · metaball 流体

22K 粒子 via BufferGeometry + ShaderMaterial。加法混合辉光、cyan/magenta on near-black、滚动相机。载入 ~150KB gz，必须版本化 CDN + IntersectionObserver 懒加载。

无依赖。DPR 自适应。trail fade 而非全清，可读为"残影"。实时数据用 ring buffer + 自动 fit min/max。下方是 live 演示。

§7 — PRODUCT REGISTER

Product 注册：设计服务产品

仪表盘 · 后台 · 分析 · 数据表 · app shell · 设置 · 工作台 · 电商。优化方向：清晰 × 密度 × 可用性。 不继承 brand 的 grain / vignette / 大 hero 字 / dark-default / 真引擎 — 这是不同的设计语言。

产品底层 Reference: product-ui.md §0

Off-tint page

页面绝非纯 #fff / #000。向 brand hue 染色。深色面板向上变亮，亮色面板向下变浅。

Hairline or none

卡片要么用 1px 7% 透明度边，要么完全无边界由阴影分隔。绝不允许硬 #ccc 框。

Whisper tinted shadow

0 1px 3px rgba(ink-tint,.05)，向 ink 染色。大阴影只给浮动外壳 / 模态。

Distinct palette

禁止蓝+绿+橙通用三件套！选 §4 的 12 种 past-ready 组合，或自配 5 中性色阶 + 16 强调色。

KPI anatomy

顶部图标 chip + 状态 chip → 标签 → 大数字（tabular-nums，从 0 计数）→ 可选 sparkline。统一走这套。

SPECTACLE = 1–4

仪表盘不要 hero 引擎。仅做反馈型动效：reveal stagger、number roll-up、chart draw-on。

    §11 — COMMERCE REGISTER

    电商注册 brand 灵魂 + product 任务的混合体

    商品详情页（PDP）卖氛围，可以保留灵魂；列表页（PLP）·购物车·结账走任务（密度高、奇观低）。 每页按其工作路由。

    PDP
    商品详情

    画廊 + 信息列（桌面 sticky）。变体不可隐藏只可禁用 — 抹去尺寸 = 假装没有。CTA 主+次不并列。

    PLP
    列表 / 类目

    repeat(auto-fill, minmax(220px,1fr)) · 卡片基线对齐（底部锁定的 CTA）· 过滤器实时反映 N 个结果。

    CART
    购物车

    就地编辑数量 / 变体 / 删除（小计随改而变）。空购物车是引导状态而非空页。

    CHECKOUT
    结账

    三步而非一堵墙 · guest 可结 · 费用从第一个字段起就透明（不允许 drip pricing）· 订单号 + 明细 + 寄达预估 = 当下最高信任时刻。

    ⚠ 暗黑模式黑名单（不只是风格 — 多国法规可罚）

    • 假倒计时（刷新会重置）
    • 假库存 / 假"14 人正在看"
    • opt-out 默认勾选
    • 隐藏费用（drip pricing）
    • 虚假比较 / 伪造销量
    • 强迫账户注册才结账
    §12 — ANTI-SLOP CHECKER

    廉价感自检 30 秒决定能不能 ship

    完整黑名单在 references/anti-cheap.md。这是节选 — 勾选你的页面，告诉你失分项。

    布局 / 视觉 / 类型 / 内容

    ❶ 没有 em-dash 装饰 作为排比、戏剧停顿、装饰性旁白 — 即便已经写出来了
    ❷ eyebrow 数量 ≤ ⌈sections / 3⌉ 每节顶部那个超细 uppercase 标签 — AI 最爱滥用
    ❸ 没有渐变文字作默认招式 background-clip: text 双色 duotone 可例外；单独禁止
    ❹ 没有 AI 紫蓝光（除非明确要） 渐变按钮 · 霓虹 mesh 背景 · 发光 CTA
    ❺ 没有假精确数字 92%、4.1×、48k 假装为规格
    ❻ 字体不是 reflex 默认 Inter / Fraunces / Instrument Serif / Playfair / Cormorant / Space Grotesk / Syne / DM Sans 等 — 用它们要说出理由，否则换新的

    图表 / 数据 / 交互

    ❼ 柱状图有 x 轴标签 & height = value/max 不出现均匀高 / 顶到框 / 太细 / barcode 的失败
    ❽ 趋势用线 / 面积，不用柱 一根根细瘦列墙 = 错了图类型
    ❾ 不用 div 假装"产品截图" 除非这 div 是该产品的自有组件（CMS 预览、教学图），不是赝品
    ❿ 没有任何 motion 被声称却未实现 说的 SPECTACLE 7 但页面静止 = 谎言
    ⓫ 总是提供 prefers-reduced-motion 兜底 reveal stagger / magnetic / canvas loop 都必须冻结到静态帧
    ⓬ 对比度 WCAG AA（按钮 · 占位 · 错误文字） 不只是测纯背景，要测"按钮上文字 vs 按钮 bg"
