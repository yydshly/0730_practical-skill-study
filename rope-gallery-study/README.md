## rope-gallery 是什么

一个 **Awwwards 风格的 WebGL 交互画廊**，核心效果：

> 多张图片卡片悬挂在一条绳子上，绳子在两点之间自然下垂并随风晃动，
> 用户可以拖拽、滚动或用键盘方向键左右移动浏览卡片。

### 技术栈

| 技术 | 用途 |
|------|------|
| Three.js 0.169 | 3D 渲染引擎 |
| GSAP 3.12.5 | 补间动画和键盘缓动 |
| 自定义 GLSL 着色器 | 绳子三股绞线 + 纤维噪声 + 边缘光照 |
| Vite | 构建工具 |

### 物理系统架构

rope-gallery 的核心不是 Three.js 的物理引擎，而是一套**手写的弹簧链模拟**：

```
绳子弹簧链（1D Wave Chain）
├── Y 轴波动：重力 + 张力 + 阻尼
└── Z 轴波动：惯性延迟（拖拽时卡片拉扯）
```

卡片叠加了 **6 种运动层**，使其交互自然：

| 运动层 | 行为 |
|--------|------|
| 钟摆摆动 | 悬挂点受绳子加速度驱动 |
| 滞后弹簧（lag spring） | 拖动时卡片延迟跟随 |
| 邻居排斥 | 防止卡片重叠 |
| 重量弹跳（weight bounce） | 减速时卡片上下颤动 |
| 空闲微晃（idle sway） | 无操作时持续小幅摆动 |
| 接触阴影 | 随摆动角度漂移 + 速度变淡 |

## 使用场景分析

### ✅ 适合的场景
- **作品集 / 风格展示页**：自然、拟物的交互让内容更有记忆点
- **品牌叙事页面**：卡片形式天然适合横向故事线
- **游戏 HUD / 关卡选择**：悬挂的视觉隐喻让导航有重量感
- **移动端 HCI 交互展示**：支持触摸拖拽和手势

### ❌ 不适合的场景
- 需要大量文字信息展示的页面
- 已有明确导航结构的管理后台
- 纯功能性界面（效率优先）

## 对我们的意义

我们已有的人像风格研究项目（`female-portrait-style-gallery`）是**静态网格画廊**，用户只能点击查看。

rope-gallery 提供的价值：**把静态风格展示变成有重量的物理交互体验**。

结合点：
- **20 种人像风格** → 20 张悬挂卡片
- 悬拄物理 → 风格之间有"手感"的切换
- 钟摆摆动 + 惯性延迟 → 让不同风格之间切换有递进感
- 自定义 GLSL 绳子 → 可以做成画轴/卷轴造型

## 定制样例

`custom-sample/` 中基于 `female-portrait-style-gallery` 的 20 张风格图片，
复用了 rope-gallery 的弹簧链物理系统，但做了以下定制：

1. **内容替换**：8 张儿童教育卡片 → 20 张人像风格图片
2. **绳索改成画轴**：哑光黑木材质感（修改 GLSL uniform）
3. **卡片投影改成卷轴装裱**：金色边缘（修改 `clipBodyMat`）
4. **主题色调**：绿色教育主题 → 中式典雅金/墨色系
5. **键盘快捷提示**：显示当前风格序号
