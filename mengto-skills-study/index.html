核心哲学

这个库建立在四个核心原则之上，驱动着每一个技能的设计方式。

Principle 01

Prompts are assets

好的提示词应该被版本化管理、存入技能库，而不是用完即弃。一次好的提示词 = 永久可复用的资产。

Principle 02

Specs beat vibes

最快速获得一致输出的方式：清晰的约束条件 + 明确的层级结构 + "只改 1-2 处"的迭代纪律。

Principle 03

References beat paragraphs

截图承载着字体、间距、颜色、布局节奏——这些信息密度远高于文字描述，且无可歧义。

Principle 04

Skills are operating procedures

好的技能精确告诉 AI：何时使用、如何启动、用什么默认值、以及需要避开哪些坑。

SKILL.md 标准格式

每个技能遵循统一的文件契约，前 Matters 作为触发器，正文作为工作流执行手册。

--- name: video-to-superprompt description: Turn a reference video into a super detailed recreation or inspiration prompt. Use when the user provides, mentions, uploads, links, or points to a video and asks to analyze the design, UI, animations, transitions, scroll interactions... --- # Video To Superprompt ## Goal Convert any usable reference video into a builder-ready prompt that captures what the video shows... ## Workflow 1. Locate the source video. Accept local paths, uploaded files, URLs... 2. Inspect technically. Run ffprobe for metadata, extract frames with ffmpeg... 3. Analyze in layers. Story / Screen-layout / Motion / Visual design / Technical rebuild... 4. Plan assets. Produce an asset map with exact URLs... 5. Write the superprompt. Start with the final thing to build... 6. Verify before finalizing. Confirm all asset paths exist... ## Quality Bar The prompt should be long enough to rebuild the interaction without seeing the original video. Include exact motion mechanisms: pinned section, scrubbed timeline, video.currentTime, parallax... ## Pitfalls Generic landing-page sections, decorative blobs, mismatched stock media, autoplay-only video...

技能文件夹契约

每个技能文件夹的标准化结构，确保 AI 智能体可以无歧义地找到所需文件。

agent-skills/<category>/<skill-name>/ ├── SKILL.md # 必需：frontmatter + 工作流 ├── REFERENCES.md # 可选：仅链接 ├── ARTICLE.md # 可选：长文解释 ├── assets/ # 可选：图片/模板 ├── scripts/ # 可选：辅助脚本 └── demo/ ├── index.html # 可移植独立 HTML ├── PROMPT.md # 精确复现提示词 ├── preview.jpg # 1280×720 截图 ├── source.json # Neuform 溯源数据 └── assets/ # demo 本地资源
