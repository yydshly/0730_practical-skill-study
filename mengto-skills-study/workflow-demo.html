✍️ Step 3: 生成的交互 Prompt 示例 可复用

按 SKILL 规定的结构（Core idea / Technology / Implementation / Interaction / Success）拆分出 3 个可复用 Prompt：

Prompt A · Hero Title Split + Scale

  • Core idea: 标题文字在滚动进入时分裂成两半，同步执行 scale 动画
  • Technology: GSAP + ScrollTrigger + SplitText / clip-path
  • Implementation: GSAP timeline scrubbed to scroll position, clip-path reveal left/right
  • Interaction: 纯 scroll 驱动，无 hover/mouse 依赖
  • Success: 0–4s 时间窗口内完成，reduced-motion fallback 为 opacity fade

Prompt B · Card Stack Pinning

  • Core idea: 三张卡片在视口内钉住并依次堆叠，形成交卷叙事感
  • Technology: GSAP ScrollTrigger pin + stagger
  • Implementation: 3 cards pinned simultaneously, stagger 0.15s between each
  • Interaction: Scroll position maps to cards' translateY, pin duration = 200vh
  • Success: 10–16s 时间窗口，每张卡片停留时间相等

Prompt C · Footer Reveal

  • Core idea: 最后一张卡片揭开页脚，形成从有到无的叙事收尾
  • Technology: z-index layering + scroll progress → opacity
  • Implementation: Final card has decreasing opacity as scroll exceeds pin threshold
  • Interaction: Opacity 1→0 mapped to scroll 80%→100% of pin section
  • Success: Footer 完全可见时 final card opacity = 0

工作流总结

4 步闭环评估

哪些步骤可以本地跑通，哪些需要平台

步骤 技能 本地可跑 依赖 验证结果
① video-to-superprompt ✅ 部分 ffprobe / AI 模型 ffprobe ✅ 实测元数据获取，AI superprompt 输出需模型
② html-to-interaction-prompts ✅ 完全 无外部依赖 源码分析 + 截图捕获 + 3 个 Prompt 块生成，全流程可跑
③ stitched-full-page-capture ⚠️ 需工具 Puppeteer / Playwright Demo 可内嵌预览，完整长图拼接需 headless 浏览器
④ build-daily-inspiration-sites ❌ 需平台 Codex Sites API 只能验证合约规范，5 个 site 的私有部署无法本地演示

💡 关键发现

  • ②html-to-interaction-prompts 是最有价值的单步：无需任何外部工具，直接读 HTML → 写 Prompt → 捕获截图，零摩擦
  • ③的瓶颈是截图工具：Puppeteer 可以本地安装，不需要 Codex 平台
  • ④是完整的 SaaS 产品调用：这个 SKILL 本质上是给 Codex Agent 用的 SOP，不适合本地复现
  • 整个工作流的核心价值：建立了一套"灵感 → 拆解 → Prompt → 截图 → 构建"的标准化流程，让 AI Agent 的输出可验证、可沉淀
