animation-on-scroll 🎬 动画

IntersectionObserver + Tailwind 的滚动动画触发器。零依赖，Tailwind 友好，prefers-reduced-motion 降级。

使用场景：需要给一组元素加渐入动画，不想引入 GSAP 等重型库

IntersectionObserver → toggle class "animate" .animate-on-scroll { animation-play-state: paused } .animate-on-scroll.animate { animation-play-state: running }

gsap 🎬 动画

GSAP 时间线、ScrollTrigger、stagger、transform 动画。含常见坑点（FOUC、布局属性动画、overflow）。

使用场景：需要做复杂的时间线动画、滚动驱动叙事、多元素交错动画

gsap.timeline({ defaults: {ease:"power2.out"} }) .from(".nav", { y:-20 }) .from(".hero", { y:30 }, "-=0.2")

cinematic-gsap-lenis 🎬 动画

完整电影感运动系统：GSAP + ScrollTrigger + Lenis 平滑滚动。含文字交错、视差、pinned section、magnetic hover、custom cursor。

使用场景：需要做 Awwwards 级精品网站：文字逐词显示、滚动粘滞、鼠标跟随光标

lerp: 0.08, smoothWheel: true power3.out ease, 0.85s duration scroll scrub: 0.8 ~ 1.4 stagger: 0.055s (words), 0.11s (lines)

staggered-word-reveal 🎬 动画

逐词淡入上升的编辑级文字动画。IntersectionObserver 触发，只执行一次，适合 headline。

使用场景：落地页大标题需要精致的逐词显示效果，不需要 GSAP SplitText

opacity: 0 → 1, translateY(20px) → 0 duration: 0.8s, ease: cubic-bezier(0.16,1,0.3,1) stagger: 0.07s per word trigger: top 82%

使用场景：落地页顶部和底部需要模糊渐变遮罩，配合毛玻璃导航

backdrop-filter: blur(0.5px) ~ blur(64px) mask: linear-gradient(to top, rgba(0,0,0,0) 0%, ...) 6 layers composited with z-index
