# 项目来源说明与阶段收尾设计

日期：2026-08-02

## 目标

在不改变任何工具算法的前提下，清楚展示本项目参考的在线网页、对应的官方 GitHub 源码库、许可证和当前实现关系；同时给出截至当前提交的阶段进展，让用户查看本地预览后再决定是否提交本轮说明代码。

## 设计契约

- Entry mode：revision-led，本轮只收尾说明和阶段边界。
- Target user and context：正在验收中文工具站的项目负责人。
- Desired first impression：一眼看清参考来源、官方源码、独立实现关系和当前是否全部完成。
- Visual ambition：Functional。
- Experience architecture：Editorial Flow。
- Visual constraints：复用现有能力总览卡片、边框、圆角和文字层级；不重新设计页面。
- Information constraints：不得暗示本项目是官方版本、官方镜像或已完整复刻；不得暗示此前已经系统使用官方源码。
- Operation constraints：外部链接在新标签页打开，并带 `noopener noreferrer`。
- State constraints：来源说明为静态事实，不影响筛选、工具运行和结果状态。
- Environment constraints：当前本地预览 `http://127.0.0.1:4174/`；桌面和 390px 宽度均需可读。
- Primary journey：打开能力总览 → 阅读来源和进展 → 打开任一工具 → 在能力说明底部再次看到来源与独立实现声明。
- User-defined phases：① 当前进展收尾总结；② 说明参考网页和官方源码；③ 展示后由用户决定是否提交。
- Required artifacts：能力总览来源区、工具说明来源区、自动化测试、构建结果、浏览器展示证据、未提交变更清单。
- Autonomy authorization：用户已要求完成说明并展示。
- User-decision boundary：是否提交本轮代码由用户展示后决定；本轮禁止提交。
- Observable completion criteria：两个页面层级都能访问在线网页和官方源码；明确 MIT、独立中文实现、此前主要参考网页可见行为、尚未全部完成；筛选仍工作；390px 无横向溢出；测试和构建通过；Git 状态显示本轮变更未提交。
