## 设计契约

| 项目 | 已确认内容 |
|---|---|
| Entry mode | Brief-led |

| Observable completion criteria | 九类筛选、搜索、详情、复制、错误/空状态可操作；1440、768、390 三个视口无阻断布局；Node 测试和浏览器验收通过。 |

## 浏览器验收记录

- 运行环境：本机 Chrome 无头模式，通过 Python Playwright 驱动；应用内浏览器连接器因其运行缓存路径缺失无法初始化，改用本机浏览器完成同等验收。
- 验收入口：`http://127.0.0.1:43173/` 与直接打开 `index.html` 的 `file://` URL。原计划端口 4173 已被另一个本地项目占用，因此 HTTP 验收使用独立端口 43173。
- 自动验收命令：`python tests/browser-smoke.py`。
- 视口：1440 × 1000、768 × 960、390 × 844。
- 结果：HTTP 与 `file://` 入口均为 20 卡片、20 条提示词摘要且无页面脚本错误；390px 对两种入口均完整执行分类键盘激活、中文分类标签搜索、详情打开、提示词复制、Esc 关闭和焦点返回；另以重复 ID 目录验证了可读错误页和停止正常渲染；空状态重置、缺图反馈和三个视口溢出检查全部通过。
