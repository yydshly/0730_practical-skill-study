# 双样例对比设计

## 目标

每一种人像风格同时保留现有的原有样例，并增加一张由 Gemini 依据相同提示词生成的样例。访问者可以在卡片和详情弹窗中切换来源，直接比较两种成片效果。

## 数据与素材

- 现有样例继续使用 `assets/styles/<编号>-<风格>.png`。
- Gemini 样例保存为 `assets/styles/gemini/<编号>-<风格>.png`，与现有风格 ID 一一对应。
- 每条风格数据增加 `geminiImage` 与简短的 `geminiDescription`；原有 `description` 与 `prompt` 不被替换。

## 页面交互

- 每张风格卡片增加“原有样例 / Gemini 样例”两段式切换控件，默认显示原有样例。
- 切换后更新卡片图片、图片替代文本和来源标记；风格名称、简介与完整提示词保持不变。
- 详情弹窗同步提供相同切换，方便放大查看同一风格的两种结果。
- 所有切换控件使用语义按钮和明确的当前状态，键盘与移动端均可操作。

## 验收标准

- 20 条风格均具备两张可加载的本地 PNG，且编号、风格 ID 与提示词正确对应。
- 首屏展示原有样例；切换 Gemini 后显示对应的 Gemini 成片，切回后可恢复原图。
- 搜索、分类、复制提示词、详情弹窗及现有桌面/平板/手机回归测试均保持可用。
