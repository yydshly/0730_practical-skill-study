# 女性人像风格样例画廊：设计规格

## 目标

新建一个独立静态项目 `female-portrait-style-gallery`，用 Codex 内置生图重新制作女性人像提示词导演库的全部 20 个风格样例。它展示的是各风格的最终视觉效果，不依赖 MiniMax、API Key 或后端服务。

## 背景与范围

现有 `female-portrait-director-demo` 的 Playground 将样例浏览、提示词编辑和 MiniMax 在线生成放在一起，且目前的图片质量未达到展示要求。新项目只承担“可信、高质量的风格样例浏览”这一职责。

包含：

- 20 个路由风格各一张新的项目内置样例图；
- 9 个分类的筛选和关键词搜索；
- 卡片浏览、大图详情、镜头/场景/光线拆解和提示词复制；
- 桌面、平板、移动端的响应式布局；
- 筛选与搜索逻辑的自动化测试及真实浏览器验证。

不包含：

- 运行时生图或第三方 API 集成；
- API Key、用户账号、历史记录或上传参考图；
- 对原有 demo 的修改或替换。

## 视觉方向

采用高级暗色影棚风：近黑色渐变基底、暖铜金色作为交互强调、人像样例占据主要视觉权重。风格像一册可浏览的摄影档案：排版克制、留白充足、信息层级清晰，不以过多的界面装饰分散对样例质量的注意力。

所有图片都使用虚构、明确成年的女性人物。每张图保持统一竖幅摄影比例；通过不同的服装、场景、动作、构图、光线与成像质感体现 20 个风格之间的差异。

## 信息架构与交互

### 首页

- 顶部展示项目名、样例数量与简短说明；
- 分类筛选条覆盖 lifestyle、curve、fashion、fantasy、commercial、oriental、beauty、realism 与 cinematic；
- 搜索框同时匹配中文名称、分类、关键词与描述；
- 作品区按当前结果渲染视觉卡片，桌面四列、平板两列、手机单列；
- 空结果提供明确提示与“重置筛选”操作。

### 样例卡片

每张卡片显示编号、风格名、分类、视觉摘要和图片。悬停/聚焦时放大图片并显示查看详情的明确反馈；卡片可通过鼠标、触摸和键盘激活。

### 样例详情

点击卡片会打开可关闭的沉浸式详情层，包含原尺寸大图、风格说明、场景/服装/镜头/光线要点、完整生图提示词以及复制按钮。Esc、关闭按钮和遮罩点击均可关闭详情；焦点不会遗留在已关闭的详情中。

## 技术方案

项目使用原生 HTML、CSS 与 JavaScript，不引入构建工具或运行时依赖。双击 `index.html` 或通过任意静态 HTTP 服务都可运行。

`assets/styles/` 存放 20 张正式生成图；`js/styles.js` 为单一风格数据源，定义图片路径、元数据、摄影拆解和用于生成该样例的最终提示词。`js/gallery.js` 负责纯数据函数、筛选、搜索和 DOM 渲染；`js/main.js` 负责页面状态、详情层与复制操作。布局和视觉样式集中于 `styles.css`。

这种分层可让每个新样例的内容只需要在一个结构化条目中维护，也使筛选、搜索等行为在不依赖 DOM 的情况下可测试。

## 数据与错误处理

每个风格条目包含唯一 id、两位编号、名称、分类、关键词、描述、图片路径、摄影拆解和最终提示词。初始化时会验证 id、分类、图片路径和必填展示字段；若图片无法加载，卡片保留文字信息并展示可辨识的占位状态。复制失败时显示可理解的提示，不将失败静默吞掉。

## 验证标准

- 数据验证、分类筛选、关键词搜索及重置行为具备自动化测试；
- 20 个条目均可渲染，且静态资源路径可被页面加载；
- 在桌面与移动视口中分别检查版式、筛选、搜索、详情层、Esc 关闭和复制操作；
- 最终图片经人工检查，确认没有水印、明显失真或与该风格不符的视觉元素；
- 页面构建（如适用）与测试均无错误或警告。
