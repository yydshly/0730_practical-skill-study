Next Steps · 落地路径

如何将动效库融入现有工作流？

复用现有模板 → 定制业务参数 → 批量生成视频内容，三步完成静态到动态的内容升级。

Step 1

克隆 & 运行

克隆 hyperframes-motion-library 到本地，运行 npm install && npm run dev，在模板库中选择适合业务的模板，修改 JSON 参数后渲染。

Step 2

业务参数定制

将 gc-minimal-zine-poster 的设计数据（如风格名称、效率数字、用户量）作为参数传入模板，生成定制化视频内容。

Step 3

Agent 扩展新模板

参考 AGENT_GUIDE.md 规范，将项目文件夹交给 Agent，辅助设计新的业务专属模板，如"海报风格对比动效"、"设计流程时间线"等。
